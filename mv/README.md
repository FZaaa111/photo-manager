# 开心往前飞 · 代码 MG 动画 MV

纯代码（Canvas 2D）绘制的 77 秒 MG 动画 MV，所有画面都由时间 `t` 决定，歌词字幕按人声时间轴逐字点亮（卡拉 OK 效果）。

- `index.html`：可直接用浏览器打开的成品（字体、歌曲已内嵌），点「播放 MV」即可，空格暂停，底部可拖动进度。
- `mv.mp4`：1920×1080 / 30fps 渲染好的视频。

## 重新生成

```bash
pip install fonttools brotli
python3 build.py                                    # src/mv.html + assets → index.html
NODE_PATH=$(npm root -g) node preview.mjs out 14.5 30  # 截取若干时间点的静帧
NODE_PATH=$(npm root -g) node render.mjs mv.mp4     # 逐帧渲染并合成音频（需要 ffmpeg 与 playwright）
```

歌词时间轴写在 `src/mv.html` 的 `LYRICS` 里，节拍与音量包络在 `assets/feat.json`（librosa 分析得到）。
字体：ZCOOL KuaiLe（站酷快乐体，SIL OFL）。
